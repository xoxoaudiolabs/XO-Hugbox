# XO-Hugbox emulator

Double-click `index.html` (one self-contained file, works offline from `file://`). Click **Power on** to start audio.
The **Firmware** picker switches between the main instrument and the hardware bring-up test.

- Pads: click/hold, or keys `1 2 3 4 / Q W E R / A S D F / Z X C V` (top row = pads 0-3). Shift = Shift key or the orange key.
- Knobs: drag up/down or scroll (hold Shift while dragging for fine).
- Power slider on the device, battery voltage slider, OLED/PCF8574 fault simulation, serial monitor, scope,
  and a line-out vs. speaker listening option (the speaker path is an approximate filter, not a measurement).
- **Phones:** just the Hugbox, full screen (tap Play); "Emulator panels" in the corner shows the rest.
- **Web app:** served over https (or from localhost) it can be installed ("Install app" in the panels; on iPhone,
  Share > Add to Home Screen) and then works offline. To host it, copy `index.html`, `manifest.webmanifest`, `sw.js`
  and `icons/` into one folder; all paths are relative.

## What runs

The emulator runs **the same C++ as the board**: `firmware/lib/hugbox_core`, compiled to WebAssembly with emscripten
(WSL). Only the platform layer differs (`sim/wasm_main.cpp` here, `firmware/src/hugbox/main.cpp` on the board).
The OLED is a real U8g2 `SH1106_128X64_NONAME_F` object with `U8G2_R2`, so the pixels are exactly what U8g2 produces;
the emulator shows the SH1106 RAM rotated 180° because the module is mounted upside down (tick "show raw panel
orientation" to see what the panel itself holds). Audio is rendered in 128-frame blocks at 44.1 kHz like the I2S task.

| File | Role |
|---|---|
| `firmware/lib/hugbox_core/hugbox_app.h` | Platform-independent `App` interface: `begin / loop(nowMs, Inputs) / render(stereo, frames)` + `Platform` (U8g2 object, PCF present, log, big-buffer alloc). |
| `.../model.*` | Device state: parameter table, knob pages, scales, chord builder, sequencer steps. |
| `.../main_app.*` | The instrument: views, status line, knob pages with pick-up, shift map, sequencer clock, chord mode, arpeggiator, modes. Control map at the top of `main_app.h`. |
| `.../engine.*`, `dsp.h` | Sound: 6-voice synth (PolyBLEP saw/square, sine, noise, 2-op FM, TPT state-variable filter, ADSR, drift, glide) and the 16-pad sample player (pitch, decay, filter, level, pan, choke). |
| `.../fx.*` | Master FX: drive, bitcrush, LOFI, tempo-synced ping-pong delay, low cut. |
| `.../mic.cpp` | Mic sampling: recorder, sample editor (XOXO Studio's), user samples. In the emulator the computer's mic ("Use mic") stands in for the INMP441 and samples live in IndexedDB. `tools/sample_test.js` checks the flow headless. |
| `.../io.cpp` | Projects (autosave + 8 slots, SETTINGS pad grid) and MIDI (notes, CCs, clock in/out). In the emulator projects live in `localStorage` and MIDI goes to the MIDI card (monitor + optional Web MIDI devices). |
| `.../kit.cpp` | Built-in kit: 16 one-shots synthesized into memory at boot (~0.8 MB, PSRAM on the board). |
| `.../bringup_app.*` | Port of `firmware/src/bringup/main.cpp` (bring-up test in the emulator). |
| `sim/wasm_main.cpp` | Browser platform layer: C exports `hb_init(oled, pcf, app) / hb_set_inputs / hb_loop / hb_render / hb_panel / hb_status`. App 0 = instrument, 1 = bring-up. |
| `src/index.html`, `src/emulator.js` | UI: device drawn to scale from `layout.py`, input, WebAudio, OLED, serial. |
| `src/layout.js` | Generated by `gen_layout.py` from `hardware/layout.py`. |
| `src/hugbox_core.js` | Generated by `build_wasm.sh` (WASM embedded). |
| `index.html` | Generated by `bundle.py` (everything inlined). |
| `manifest.webmanifest`, `sw.js` | Web app manifest and service worker (offline; the page is network-first so updates show on the next online launch). Bump `CACHE` in `sw.js` when the icons or manifest change. |
| `icons/` | App icons, generated by `tools/make_icons.py` from the layout. |

## Rebuild

In a Linux/WSL shell with emscripten (`emcc`), from `sim/`:
```bash
./build_wasm.sh
```
`build_wasm.sh` compiles `firmware/lib/hugbox_core` + U8g2 (from the PlatformIO cache under `firmware/.pio/libdeps`)
and re-bundles. Rebuild after any change in `firmware/lib/hugbox_core` so the emulator matches the board.
After UI-only edits: `python bundle.py src/index.html index.html`. After `layout.py` changes: `python gen_layout.py` first.
